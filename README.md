# Pokédex Field Notes

A React + Vite Pokédex built with PokéAPI. The app includes a national catalog, live search, routed specimen profiles with type weaknesses and base stats, and a 3v3 turn-based Battle Lab.

## Run locally

```sh
npm install
npm run dev
```

## Deploy to GitHub Pages

The Vite base path and `gh-pages` scripts are configured for the `HW3_niluhlasmi_Web` repository.

1. Push the project to the `main` branch.
2. Run `npm run deploy`.
3. In the repository’s **Settings → Pages**, select the `gh-pages` branch as the source.

The site URL will be `https://<your-github-username>.github.io/HW3_niluhlasmi_Web/`.
